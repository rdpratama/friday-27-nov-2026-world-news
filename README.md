# Friday 27 November 2026 — the world in one image

A newspaper front page summing up Friday 27 November 2026: **48 stories, 6 regions + world, 14 fields**.

- Giant date masthead, count line, "THE DAY IN UTC" timeline strip and "THE DAY IN NUMBERS" strip.
- 3 hero panels + 10 medium panels, each with an original drawn scene: the Kuwait drone strike that killed two Italians, the Thanksgiving storm that cut power to 800,000, the marathon Game 3 draw in the World Chess Championship, and more.
- "WHERE IT HAPPENED" world map with region counts, a DATE CHECK box (pre-dated and not-yet stories left out on purpose), and a numbered list of the rest of the day.
- Source tags CONFIRMED / OFFICIAL / REPORTED on every card. Every story was verified against live sources on 27 November 2026; anything that could not be verified was left out.

The program is Python 3.13, standard library only: it draws the page with its own PNG encoder, canvas and 5×7 bitmap font and writes `/output/entry.png` (1024×1024, deterministic).

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`
